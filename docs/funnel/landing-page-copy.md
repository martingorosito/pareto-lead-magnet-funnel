# Lead Magnet Landing Page

Copy for the landing page, section by section. The five sections follow the page structure set for this launch, in that order: **Hero, What's inside, Who it's for, Proof with real Pareto numbers, CTA with the form.** Inside that structure, the copy uses the Day 5 and Day 6 rules: the hero has all four parts (outcome headline, sub-headline, real imagery, proof above the fold), each section answers one objection, and because 58% of visitors never reach the form (Day 5), every section repeats the same single CTA.

- **Tool:** GoHighLevel (Sites → Funnels). Chosen because the form, the redirect, the calendar, the pipeline and the four workflows all live in one account, so the whole chain can be tested end to end. The brand look matches the Pareto deck: near-black background `#070C10`, emerald accent `#10B981`, white text, headings in Plus Jakarta Sans and body in DM Sans.
- **Funnel name in GHL:** `Bottleneck Audit Funnel`
- **Page name in GHL:** `Lead Magnet Landing Page`, path `/`
- **One goal, one CTA:** every button says **"Get my free audit"** and scrolls to the form section (anchor `#get-audit`). No navigation menu, no other links.

## Build it in GoHighLevel (about 40 minutes)

1. **Create the funnel.** Sites → Funnels → New Funnel → From Blank. Name it `Bottleneck Audit Funnel`.
2. **Add three steps**, in this order, each with a clean path:
   - `Lead Magnet Landing Page` → `/`
   - `Booking Page` → `/book`
   - `Thank You Page` → `/thanks`
3. **Set the brand once.** In the page builder's Settings → Typography and Colors, set Plus Jakarta Sans for headings, DM Sans for body, background `#070C10`, primary `#10B981`. Every section then inherits it.
4. **Build the 5 sections** top to bottom as above, one full-width section each, and name each section in the builder exactly as here (Hero, What's inside, Who it's for, Proof, CTA with the form). Use a 4-column row for the stats and the Testimonial element for the quotes.
5. **Wire the CTAs.** Give section 5 the element ID `get-audit`. Set every "Get my free audit" button to Action → Scroll to Element → `#get-audit`.
6. **Embed the form** in section 5: add a Survey element and pick `Qualifying Form` (build that first, see the qualifying form doc).
7. **Upload imagery** (audit mockups, licensed only) to Media Storage, and add alt text.
8. **Check mobile.** Switch to mobile view and make sure the hero headline, button and proof strip all fit on the first screen.
9. **Publish** and connect a domain (Settings → Domains), or use the funnel's preview link. Open the page in a private window to check it loads without a login.
